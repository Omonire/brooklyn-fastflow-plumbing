# Brooklyn FastFlow Plumbing Landing Page (2026 Edition)

A futuristic, high-conversion landing page for Brooklyn's fastest emergency plumbing service. Re-engineered for 2026 with a focus on rapid dispatch and glassmorphic UI.

## Deployment to Vercel

This project is Vercel-ready. To deploy:

1.  Push the code to a GitHub repository.
2.  Connect the repository to your Vercel account.
3.  Vercel will automatically detect the `index.html` and `vercel.json` for a seamless static site deployment.

## Key Features

- **2026 Modern Aesthetic:** Glassmorphism, deep rose/slate palette, and high-impact typography.
- **GSAP & ScrollTrigger:** Advanced 3D scroll animations, section reveals, and dynamic hero parallax.
- **Hero Video Background:** Immersive water/plumbing visual theme for immediate brand impact.
- **Conversion Optimized:** AI-dispatch focused copy and prominent "45-minute guarantee" CTAs.
- **Tailwind CSS:** Fully responsive layout using the modern Tailwind ecosystem.

## Technical Details

- **Animations:** Powered by GSAP 3.12.5.
- **Icons:** Google Material Symbols (Outlined).
- **Configuration:** `vercel.json` includes `cleanUrls` for professional routing.
