# Brooklyn FastFlow Plumbing Landing Page

This is a single-page landing page for Brooklyn FastFlow Plumbing, designed for high conversion and emergency service requests.

## Deployment to Vercel

To deploy this project to Vercel:

1.  Push the code to a GitHub repository.
2.  Connect the repository to your Vercel account.
3.  Vercel will automatically detect the `index.html` and deploy it as a static site.

## Features

- **Tailwind CSS:** Styled using the Tailwind CDN for rapid development and easy customization.
- **Responsive Design:** Optimized for both mobile and desktop users.
- **Material Symbols:** Uses Google's Material Symbols for clean, recognizable icons.
- **Emergency Focus:** Clear call-to-actions (CTAs) for immediate plumbing needs.

## Future Improvements

- **Local Tailwind Build:** Convert to a local Tailwind installation for better performance and smaller file sizes.
- **Form Integration:** Connect the dispatch form to a service like Formspree or a Vercel Serverless Function to handle real requests.
- **Asset Optimization:** Host images locally to reduce dependency on external URLs and improve load times.
